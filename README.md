Electric Vehicle Market Performance & Insights

Project Overview This project analyzes electric vehicle (EV) market data using Tableau Public to explore sales, customer ratings, battery types, driving range, and drivetrain.
Project Objectives Analyze sales by manufacturer and vehicle category. Compare customer ratings across manufacturers and battery types. Study average driving range. Explore manufacturing countries and drivetrain categories. Present the analysis through an interactive dashboard.
Tools Used Tableau Public GitHub
Dataset Fields Category, Battery Type, Manufacturer, Manufacturing Country, Customer Rating, Annual Sales Units, Vehicle ID, Range Km, and Drivetrain.
Dashboard Visualizations Sales by Manufacturer Sales by Category Customer Rating by Manufacturer Vehicles by Battery Type Average Driving Range by Category Sales by Manufacturing Country Average Rating by Battery Type Sales by Drivetrain Average Range by Battery Type
Tableau Dashboard Open the Interactive Dashboard
Conclusion The dashboard presents electric vehicle market information through visualizations, helping users explore sales patterns and compare vehicle characteristics.
